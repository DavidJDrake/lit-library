# Lit Library Publication Plan (Plan 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline) — this plan is docs, a git-history rewrite, and remote operations; the only subagent seat is the independent leak audit in Task 5. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish this repository as a public GitHub project (MIT) that openly credits its AI-assisted development, with no personal or account identifiers anywhere in the tree or the history.

**Architecture:** Identifiers are replaced everywhere at once with `git filter-repo --replace-text` (blobs) and `--replace-message` (commit messages) after a full backup clone; the working tree is otherwise unchanged because Plan 4 already moved all live values into gitignored config. A root `README.md` and `LICENSE` are added before the rewrite so they are part of the clean history. An independent reviewer audits every commit for leaks before the first push.

**Tech Stack:** git-filter-repo, GitHub CLI (`gh`, authenticated as DavidJDrake).

**Spec:** decisions recorded 2026-09-02: MIT license; rewrite history in place; be explicit about Claude Code / AI-assisted development.

## Global Constraints

- Replacement map (old → new), applied to all blobs and commit messages in every commit: the real AWS account id, hosted-zone id, domain names, Cognito domain prefix, owner email, bucket/table/distribution/pool/client/API ids, and home-directory paths → the generic placeholders now seen throughout the docs (`123456789012`, `Z0123456789EXAMPLE00`, `lit.example.com`, `lit-example`, `owner@example.com`, `<books-bucket>`, `<site-bucket>`, `<downloads-table>`, `E1EXAMPLEDIST`, `us-east-1_EXAMPLE`, `exampleclientid`, `exampleapiid`, `/home/user/`). The map file itself is not committed — it necessarily contains the real values.
- Commit author email is rewritten (`git filter-repo --mailmap`) to the GitHub no-reply address, and the repo's `user.email` is set to it for future commits.
- The names "Jay" / "David J. Drake" and the GitHub account are public by choice and are NOT scrubbed. Friends' emails never appear in the repo (they live only in SSM) — verify.
- `Co-Authored-By: Claude …` and `Claude-Session:` trailers stay in commit messages (AI openness).
- Nothing is pushed until the leak audit (Task 5) reports zero matches across `git log --all -p`.
- A backup clone at `~/projects/ebook-share-backup-<date>` is taken before the rewrite and kept until Jay confirms the public repo looks right.
- Public repo: `DavidJDrake/lit-library`, description "Private ebook library on AWS — S3, CloudFront signed cookies, Cognito + Google, Lambda; React front end; Python indexer. Built with Claude Code." Topics: `aws-cdk`, `cloudfront`, `cognito`, `react`, `vite`, `ebooks`, `claude-code`.
